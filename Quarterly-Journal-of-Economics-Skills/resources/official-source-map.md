# QJE Official Source Map

Primary and authoritative sources behind the QJE-specific facts injected into this skill pack.
Access date for all entries: **2026-05-30**. Submission rules, data policy and masthead **re-verified 2026-11-23** against the live OUP Instructions to Authors, Journal Policies, Data Policy and Editorial Board pages and the Editorial Express portal (the OUP pages were read via WebFetch past their navigation; direct curl is challenge-gated). ## Official journal pages (Oxford Academic / Harvard)

- **<https://academic.oup.com/qje>** — QJE homepage. Verifies: publisher = Oxford University Press for the Harvard University Department of Economics; top-5 general-interest scope.
- **<https://academic.oup.com/qje/pages/General_Instructions>** — Author Guidelines / general instructions. Verifies: submission via Editorial Express; PDF format; pointer to the data availability policy. (Page is partly anti-bot challenge-gated to automated fetches; facts cross-confirmed via the submission portal and secondary sources below.)
- **<https://academic.oup.com/qje/pages/Instructions_To_Authors>** — Instructions to Authors (manuscript preparation). **Re-verified 2026-11-23.** Verifies: "Authors should upload a single .pdf file containing the complete manuscript" (source files only if accepted; supplementary material in separate PDFs); the first page "must give the title of the article, contributor names," the corresponding author's full address and email, and the **total word count**; the title page contains the abstract; "An abstract of no more than 250 words should be included with all submissions," with no reference citations; "Authors should provide the relevant JEL codes upon submission," placed at the end of the abstract; funding sources and acknowledgments in the first footnote (asterisk on the title); author-date citations; double-spaced, numbered pages; alt text under each figure caption. No page or word limit, no keyword requirement, and no mention of anonymous/blind review.
- **<https://academic.oup.com/qje/pages/Policies>** — Journal Policies. **Re-verified 2026-11-23.** Verifies: Editor screening with possible rejection without review, otherwise usually two independent reviewers; at submission each author should reveal financial interests, connections, funding sources, personal relationships, or direct academic competition, and disclosed conflicts appear as a statement in published papers; COPE/ICMJE standards; manuscript must not be under consideration elsewhere; anti-plagiarism screening. No AI/LLM policy and no submission fee are stated.
- **<https://editorialexpress.com/qje/>** — QJE submission portal (Editorial Express). Verifies: submission system is Editorial Express; **manuscripts must be uploaded in PDF format only**; authors must read the data availability policy before submitting; admin contact qje_admin@editorialexpress.com. **Re-verified 2026-11-23:** unchanged; step 4 uploads the manuscript "and cover letter (if any)" (cover letter optional); no fee, anonymity, or JEL text on the portal page.
- **<https://academic.oup.com/qje/pages/data_policy>** — QJE Data Policy. Verifies: publishes only if data are documented and available for replication; accepted empirical/simulation/experimental papers must provide data, programs, and computation details prior to publication; deposit to a repository linked to the journal; proprietary-data exemption still requires the programs; README PDF required; QJE adopted the AER data availability policy. **Re-verified 2026-11-23:** unchanged — post to the QJE Dataverse after acceptance; Social Science Data Editors README template recommended; submissions must include a cover letter noting proprietary data or other barriers; the page names no data editor.
- **<https://www.economics.harvard.edu/qje-data-policy>** — Harvard Economics department mirror of the QJE data policy. Verifies: same data/code requirements; cover-letter notification if data are proprietary.
- **<https://dataverse.harvard.edu/dataverse/qje>** — The Quarterly Journal of Economics Dataverse. Verifies: the deposit repository is the **QJE Dataverse** on Harvard Dataverse (distinct from the AEA journals' openICPSR).

## Process facts (no fee, timing, desk-reject) — secondary, cross-checked

- **<https://manusights.com/blog/quarterly-journal-of-economics-submission-guide>** — Secondary submission guide. Cross-confirms: **no submission fee**; **single PDF, no Word** at initial submission; five-editor Harvard team; **~2-week desk decisions** (fastest top-5); ~1-4% acceptance; ~60%+ desk-reject; referee reports typically months if past desk. Treated as secondary; the no-fee and PDF-only facts are independently consistent with the Editorial Express portal text.

## Live-check items

- **Exact current submission fee = $0**: on 2026-11-23 the official Instructions to Authors, Journal Policies, General Instructions and portal pages were read in full and **none mentions any submission fee**; secondary sources say there is none. The absence is consistent but no official page states "no fee" outright, so it stays a live-check item.
- ~~Abstract word cap~~ — **resolved 2026-11-23**: the official Instructions to Authors state "no more than 250 words" (the ~150 figure was a secondary-source error).
- **Review mode**: no official page states single- or double-blind; the instructions require contributor names on the first page, so authors should not anonymize. Not encoded as a rule.
- **Current impact factor**: reported values diverge widely across aggregators (6.662 in 2015 per JCR; later third-party figures range ~14–22). Not used as a load-bearing fact in the skills; requires a live check for a single current number.
- **Named data editor / formal reproducibility-check workflow**: QJE requires deposit to the QJE Dataverse and adopted the AER policy, but a dedicated QJE "data editor" role analogous to the AEA Data Editor requires a live check (2026-11-23: neither the Data Policy nor the Editorial Board page names one).
