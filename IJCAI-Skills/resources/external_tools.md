Access date: 2026-11-23 (moved to IJCAI 2027)

Use these tools after reopening the current IJCAI cycle pages. IJCAI rules can change by
year and by track.

## Author-side checks

- Submission-site account, author role, title, abstract, up to 3 content-area keywords,
  author information, compulsory ORCID validation, and conflicts.
- Reciprocal-reviewer designation (or a valid exemption) for every submission.
- Current author kit, PDF style, page count (7 body + up to 2 reference pages), and optional
  ethics statement.
- Anonymous paper, no acknowledgements or contribution statement, no identifying PDF
  metadata, and anonymized supplement/code/data.
- Supplementary material (appendix, proofs, data, code) within the 50MB PDF/ZIP limit.
- Whether a recent-rejection disclosure is still required (it was in 2026; the 2027 pages do
  not say).
- Author response using the current official guidance and response window.
- Camera-ready package, copyright/metadata, registration, and in-person presentation plan
  (Kyoto or Hengqin).

## Do not infer

- Do not infer IJCAI 2027 rules from IJCAI-ECAI 2026, or future-cycle dates from IJCAI 2027.
- Do not assume the same page limits, response length, PPI fee rules, submission system,
  review phases, author limits, LLM policy, supplementary-material rules, or presentation
  obligations without reopening current official pages.
- If official pages disagree, use the newest author kit, CFP update, or direct chair
  communication as the controlling source and record the conflict.
