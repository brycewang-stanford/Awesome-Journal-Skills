# 《系统工程学报》投稿预检（jse-tju-submission）

## 触发时机

当稿件内容和体例已定稿，准备注册、上传、缴纳官网明确费用或提交修改稿时使用。投稿流程、费用、
联系方式和文件要求可能变化，所有事实必须逐项回查
[`official-source-map.md`](../../resources/official-source-map.md)，不得引用代投网站或凭旧经验操作。

## 关键事实

以 source map 为准，当前官方入口明确提供在线投稿、账号注册与邮箱激活、初审、模板/排版下载、
原创性要求、版权协议下载、审稿费和录用后版面费说明。以下事项未获官方页面明确支持时必须写
“待核实”，不能补猜：

- 完整审稿周期与录用率；
- 投稿匿名方式或单独匿名稿要求；
- 审稿费/版面费之外的其他费用；
- 数据库收录状态的当前完整清单；
- 任何非官网邮箱、个人账户或中介承诺。

## 投稿文件 checklist

- [ ] 主文档按官网下载区当前模板和排版要求生成。
- [ ] 中英文题名、作者、单位、摘要和关键词对应。
- [ ] 公式、符号、图表、参考文献和附录已通过 `writing-tables-figures`。
- [ ] 图件格式、清晰度、图题和表题按官网要求复核。
- [ ] 基金、作者简介、通讯信息与系统字段一致。
- [ ] 稿件未一稿多投，重复率和已发表内容风险已自查。
- [ ] 数据、代码、许可和利益冲突/伦理事项按研究实际说明。
- [ ] 版权协议使用官网当前文件；签署时点按系统/编辑部通知操作。
- [ ] 本地文件名、版本号和最终 PDF/编译结果一致。

官方未明确要求单独匿名稿时，不擅自删除作者信息；若投稿系统字段或当次通知另有要求，以当次官方
界面为准并记录。

## 账号与在线流程 checklist

1. 只从 `jse.tju.edu.cn` 官网进入作者登录/注册页面。
2. 注册后完成官方页面要求的邮箱激活，并核对账户邮箱。
3. 在新投稿前阅读投稿须知、下载区和系统提示的当前版本。
4. 完整填写题名、摘要、关键词、作者、单位、基金和联系方式。
5. 上传后下载/预览系统生成文件，检查中文、公式、图表和附件。
6. 保存稿号、提交时间、文件版本和系统回执。
7. 初审后仅按官网系统或可由官网核验的编辑部联系方式操作。
8. 修改稿上传前逐条核对回复信、清洁稿/标记稿与系统要求。

## 费用、原创性与版权

官网投稿须知已给出审稿费和录用后版面费的具体标准；金额属于动态事实，不在此 skill 固化，
提交或缴费当日回查 source map O2 指向的官网页面。未经初审通知不提前付款，不向个人账户付款。
相似性较高稿件存在退稿风险；引用、自引、会议稿、预印本和既有成果重合应如实处理。版权协议从
官网当前下载区取得，不使用来源不明版本。

## 防诈骗核验

- 域名是否为官方 `jse.tju.edu.cn`。
- 通知中的稿号、题名和作者是否与系统记录一致。
- 收款主体、金额和流程是否可在官网/投稿系统或官方联系方式复核。
- 是否出现“保证录用”“快速通道”“代改包发”等非官方承诺。
- 可疑邮件不点附件/链接，先从官网独立进入系统查状态。
- 使用官网公布的电话、邮箱或地址反向核实，不使用可疑消息提供的新联系方式。

官网已有防诈骗提醒，证据入口见 source map O10。

## 提交前内容复核

```text
fit-positioning → 选刊成立
system-modeling / theory / algorithm → 主张与方法闭合
validation → 每条主张有相称证据
robustness-reproducibility → 边界与复现信息完整
writing-tables-figures → 当前模板和体例通过
submission → 仅核对官方流程、文件和身份
```

## 修改稿上传

先完成正文修订，再生成逐条回复；保证回复中的页码/行号与最终上传版本一致。系统若要求清洁稿、
标记稿、回复信或其他附件，按当次界面逐项命名。官网投稿须知对返修期间作者、顺序和单位变更有
明确限制，提交前按 source map O2 复核，不能到返修阶段临时调整。

## 反模式

- 从搜索广告或代投链接进入“投稿系统”。
- 把二手网站的周期、录用率、费用或收录信息写入稿件包。
- 使用旧模板或旧版权协议，不看官网下载区。
- 未预览上传文件就提交，导致公式、图件或中文乱码。
- 先交费再核对稿号、通知和官方流程。
- 把“待核实”的匿名或附件要求当成确定规则。

## 本刊投稿体例审稿期待与退稿模式

投稿须知明确要求在线投稿并进行初审，内容与格式均需满足官网材料。高风险包括一稿多投、相似性
问题、图表/参考文献不合规范、作者信息前后不一致，以及把未经核验的非官方通知当成编辑部要求。
本 skill 不推测这些风险对应的处理时长或录用概率。

## 微型走查

```text
入口：从期刊首页进入作者登录，域名核对通过
模板：当次重新下载并与源文件比对
元数据：中英文信息与稿件一致
文件：主稿、图件、附录、声明按系统当次要求
费用：仅在初审后按官网标准和正式通知核验
回执：保存稿号、最终文件和系统状态
未核实：匿名方式、完整周期——不写成确定事实
```
