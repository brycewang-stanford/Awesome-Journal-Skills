# 《系统工程学报》文献综述（jse-tju-literature-review）

## 触发时机

当综述按作者或年份排队、国内外文献彼此分离、本刊近年论文只作装饰性引用，或结尾只说
“现有研究较少”时使用。目标是构造一条能推出研究问题、系统机制与证据设计的论证链。
本刊公开样本矩阵见 [`exemplars/library.md`](../../resources/exemplars/library.md)；引用时仍应回到
论文正式元数据核对，不能把样例库当成完整检索结果。

## 输入诊断

需要题目、问题陈述、系统边界、候选贡献、已有参考文献表和检索记录。先把文献分成四条线：

1. 国内系统工程问题线：本土场景、系统结构与已有解决框架。
2. 国际理论方法线：机制理论、模型、算法、识别或预测的前沿。
3. 本刊近年对话线：同一问题层级、系统结构或证据标准的文章。
4. 增量线：本文究竟改变方法，还是改变应用边界并引出新结论。

若一篇文献不能说明“它解决什么冲突、依靠什么假设、留下什么空缺”，暂不进入正文。

## 综述矩阵

| 字段 | 要回答的问题 |
|---|---|
| 系统边界 | 文献纳入哪些主体、层级、时间和环境？ |
| 核心机制 | 网络、反馈、信息、风险或资源耦合如何起作用？ |
| 理论/模型 | 博弈、优化、复杂网络、动力系统、统计或学习框架是什么？ |
| 证据 | 证明、数值、仿真、真实数据、案例或样本外预测？ |
| 有效范围 | 哪些条件下结论成立，是否报告失败边界？ |
| 可比结论 | 与本文共享哪个问题、机制、方法或指标？ |
| 未解缺口 | 缺的是机制、可解性、识别、外推还是实施？ |

不要用“研究视角不同”填缺口；必须能落到一个模型关系、识别条件或验证设计。

## 处理步骤

### 1. 从研究问题反推检索块

按“系统对象 + 关键机制 + 方法 + 证据类型”建立组合，而不是只搜行业词。例如交通应急稿同时检索
动态路网、信息延迟、公平约束、滚动优化和扰动仿真。记录数据库、字段、关键词和筛选条件。

### 2. 建立国内系统工程线

先说明国内问题为何具有特殊系统边界、制度或数据条件，再比较已有研究如何处理相互作用。
国内线不是中文作者清单；它应暴露本文面对的真实约束和可迁移问题。

### 3. 建立国际理论方法线

围绕机制或方法的演化组织：早期假设解决了什么，后续如何放松，现有方法在哪个系统结构下失效。
英文术语首次出现时给出中文对应，模型名称和性质保持准确。

### 4. 建立本刊对话线

从近三年公开目录寻找至少三个层次：同主题、同机制、同证据类型。引用本刊文章的目的，是说明
稿件与本刊讨论的交点及新增台阶，不是人为提高本刊引用数量。

### 5. 分开方法与应用增量

- 方法增量句式：既有方法在结构 S 下因条件 C 失效；本文改变 M，因此得到性质/算法/识别 P。
- 应用增量句式：场景 A 引入过去未建模的约束/反馈 C，它改变结论 P，并由证据 E 验证。

若两类都声称，分别给证据，不用“首次结合”代替贡献。

### 6. 用缺口推出设计

综述最后一段依次写：已知、争议/边界、本文问题、本文机制、本文证据、与既有文献的差异。
每个贡献点应能回指一组最接近文献，而不是回指整个领域。

## 段落模板

```text
问题层：既有研究围绕 X 形成 A/B 两类解释，但均把 C 视为外生。
机制层：当 C 通过反馈 R 改变主体状态时，结论 P 不再直接成立。
方法层：已有 M1 能处理……却要求……；M2 放松……但不能……
本刊对话：近年本刊在相邻系统边界中讨论了……，尚未识别/求解……
本文：因此构造……，证明/计算/估计……，并用……验证适用边界。
```

## 微型示例

差的写法：“张三研究了网络韧性，李四研究了供应中断，王五采用博弈模型，已有研究很丰富。”

改写逻辑：先比较集中式与分散式网络的中断传播假设，再说明信息共享如何改变主体策略及级联阈值；
随后对比可求解模型和仿真证据，最后指出本文新增的是“内生共享决策下的传播—响应反馈”，而不是
简单增加一个行业案例。

## 反模式

- 每段以作者姓名开头，段末没有比较判断。
- 用“国内研究较少、国外研究较多”制造地域缺口。
- 只引用综述或二手聚合信息，不核对原始论文。
- 把方法新颖性写成“首次使用 AI/博弈/仿真”。
- 将同题名文献视为最接近文献，忽略系统层级和证据差异。
- 复制长摘要或正文；样例库只能提供公开元数据和自有总结。

## 期刊专属拒稿风险

综述若不能解释系统结构为何改变研究设计，稿件会像一般行业应用；若只强调数学方法，又无法与
本刊近年理论—方法—应用链对话，会出现选刊定位不清。引用动态或投稿事实时，应查
[`official-source-map.md`](../../resources/official-source-map.md)，不得从论文目录推断编辑规则。

## 输出格式

```text
【检索范围与筛选规则】
【国内系统工程线】争议—边界—缺口
【国际理论方法线】假设演化—能力—限制
【本刊近年对话线】主题 / 机制 / 证据
【最接近文献矩阵】系统边界、机制、方法、证据、结论
【方法增量】
【应用增量】
【综述收束段】
【需补检索项】
【最大拒稿风险】
```
