# 《系统工程学报》系统建模（jse-tju-system-modeling）

## 触发时机

当选题已经通过系统性检查，但模型中的边界、变量、约束和信息时序尚未闭合时使用。本 skill
负责把现实系统压缩为可分析、可求解或可识别的形式，不负责替代定理证明、算法设计或实证估计。
本刊理论、方法与应用并重的范围见
[`official-source-map.md`](../../resources/official-source-map.md)，近年模型类型见
[`source-basis.md`](../../resources/source-basis.md)。

## 输入诊断

要求提供系统图、决策/观察时序、变量草表、目标、约束、数据或计算条件，以及三条预期主张。
先做四个一致性检查：

- 每个系统组件是否在模型中有状态、行为或约束？
- 每个符号能否回指现实含义、单位和可观测性？
- 每个假设是否被后续性质、求解或识别使用？
- 每条预期结论是否有相应变量和比较维度？

若模型删除一个“核心主体”后不变，系统边界仍是背景，应返回 `jse-tju-topic-selection`。

## 建模骨架

| 模块 | 必须明确 |
|---|---|
| 边界与层级 | 系统、子系统、主体、环境；纳入与排除 |
| 集合与索引 | 节点、时期、情景、类型、状态，索引范围 |
| 状态变量 | 随时间/事件演化、由哪些转移关系更新 |
| 决策变量 | 谁在何时基于什么信息选择，连续/离散 |
| 参数 | 单位、范围、来源、估计或校准方式 |
| 目标 | 个体目标、系统目标及权衡；必要时多目标 |
| 约束 | 物理、容量、逻辑、制度、信息和耦合约束 |
| 相互作用 | 网络边、策略响应、共享资源、外部性或反馈 |
| 输出 | 均衡、最优解、轨迹、预测或可识别量 |

## 处理步骤

### 1. 画边界与信息图

分别画物质/资源流和信息/决策流。标出外生输入、系统输出、主体观测集和不可观测状态。
信息结构必须与时序一致：时期 \(t\) 的决策不能使用 \(t+1\) 才出现的信息。

### 2. 建变量字典

采用“一符号一含义”。对每项记录类别、定义、单位、取值域、索引、是否可观测、数据/校准来源。
状态变量与决策变量不得混用；随机量、实现值和期望量使用可区分记号。

### 3. 写主体与时序

按“自然/环境行动—信息到达—主体决策—系统转移—收益/成本实现”说明顺序。博弈稿要写策略空间、
信念和均衡概念；控制/动态稿要写状态方程和边界/初始条件；优化稿要写决策阶段与非预见性。

### 4. 从机制导出约束

每个耦合机制至少对应一条关系。例如共享容量进入总量约束，网络传播进入邻接/转移关系，
风险反馈进入状态或目标，异质性进入参数、类型或策略。避免在结果讨论中突然引入模型外机制。

### 5. 审计假设

逐条写“现实依据—数学作用—放松后的预期影响—验证方式”。为获得可解性而设的假设可以保留，
但必须明确它是分析装置，不冒充事实。关键结论若完全依赖窄假设，应设计边界或稳健性检验。

### 6. 检查识别或可解性

- 理论/博弈：存在性、唯一性、均衡选择或稳定性条件是否可陈述。
- 优化：可行域是否非空，变量规模和结构是否允许目标算法。
- 动态/网络：初值、边界、转移矩阵和稳定条件是否足够。
- 实证/预测：参数能否由数据区分，训练目标与实际决策目标是否一致。

不能证明完整性质时，不要暗示“显然可解”；明确数值求解范围和失败条件。

## 模型闭环测试

```text
现实组件 → 集合/变量
相互作用 → 方程/约束
信息时序 → 可行策略/特征集
系统矛盾 → 目标函数/评价指标
主张 → 定理、算法实验或估计量
边界 → 参数范围、情景或外推限制
```

若任一箭头为空，说明叙事与模型未闭合。

## 微型示例

对“企业共享中断信息的供应网络”稿件，不应只给企业成本函数。需要定义网络 \(G\)、中断状态、
企业观测、共享决策、恢复/订购行动、容量耦合和系统损失；再说明共享如何改变信念或状态转移。
若共享仅作为回归中的 0/1 控制变量，不能支持网络协同机制主张。

## 反模式

- 先堆公式，再寻找现实解释。
- 同一符号在目标函数和约束中含义不同。
- 假设“所有信息已知”，但贡献声称处理信息不确定。
- 异质主体只在文字中出现，模型参数完全同质。
- 用变量数量或非线性程度证明系统复杂性。
- 为求解方便删除关键反馈，却仍声称解释该反馈。

## 期刊专属拒稿风险

本刊候选模型的系统专属性来自结构与交互。若系统图、模型和验证三者边界不一致，或场景只给模型
换名，容易被认为是通用数学模型的浅应用。格式与符号排版要求另由
`jse-tju-writing-tables-figures` 按官方来源检查。
