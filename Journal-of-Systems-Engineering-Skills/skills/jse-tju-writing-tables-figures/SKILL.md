# 《系统工程学报》写作、图表与公式（jse-tju-writing-tables-figures）

## 触发时机

当研究内容已基本稳定，需要按本刊体例统一中文正文、中英文信息、公式符号、图表、参考文献和附录时
使用。所有可能变化的格式要求以 [`official-source-map.md`](../../resources/official-source-map.md)
为唯一事实入口；本 skill 只把已核实要求转成操作清单，不把经验性写作建议冒充编辑部规则。

## 输入诊断

收集完整稿、LaTeX/Word 源文件、全部图表、参考文献库、基金与作者信息、证明和补充材料。先分两类：

- 官方要求：模板、摘要要素、关键词、中英文信息、图表、参考文献、投稿文件等。
- 写作建议：论证顺序、图表叙事、结果压缩和附录安排。

若官网与本地旧模板冲突，停止沿用旧文件，重新下载官网当前材料并在 source map 标记复核。

## 论文结构

| 部分 | 核心任务 |
|---|---|
| 中英文题名 | 对象、系统机制与任务一致，避免口号和未证明结论 |
| 作者与单位 | 中英文对应，顺序和信息在投稿前确认 |
| 中英文摘要 | 目的、方法、结果、结论闭环；数值和方向可核查 |
| 关键词 | 覆盖系统对象、机制/方法和任务，不堆同义词 |
| 引言/综述 | 背景—问题—文献关系—缺口—内容—主要结论 |
| 模型/方法 | 边界、假设、变量、关系、求解或识别可复核 |
| 结果 | 按研究问题组织主张与证据，不按软件输出排列 |
| 结论 | 回答问题、限定边界、给系统级含义 |
| 参考文献 | 顺序与著录按官网要求逐项核验 |
| 附录 | 长证明、算法细节、补充表图与正文交叉引用 |

官网对引言和文献综述另有下载材料；可参考
[`worked-examples/01-introduction.md`](../../resources/worked-examples/01-introduction.md) 的重写过程。

## 摘要与题名

官方投稿须知对中文摘要长度、目的—方法—结果—结论要素和关键词数量给出要求，具体数值不在此处
重复固化，提交前按 source map 的 O2/O6 回查。英文题名、摘要和关键词应与中文实质对应，不做
逐字硬译。摘要要写结果方向、阈值或性能，不用“结果表明方法有效”替代信息。

摘要四句法：

1. 目的：指出系统冲突、边界和研究问题。
2. 方法：说明模型/理论/算法/数据与关键结构。
3. 结果：报告最重要、可量化或有条件的发现。
4. 结论：限定条件下给系统设计或管理含义。

## 公式与符号

- 一符号一含义，正文首次出现即定义；集合、变量、参数和随机量可区分。
- 公式编号连续，正文逐一引用；长推导移附录但保留关键机制。
- 向量、矩阵、变量、函数、单位、上下标和运算符样式按官网下载排版要求核对。
- 上下标含义保持一致；避免同一字母同时表示节点、时间和参数。
- 量纲可核查，目标函数与约束单位一致。

不要凭通用 LaTeX 习惯猜期刊字体样式；动态格式只按官方模板确认。

## 图与表

官网已给出图件、分辨率/格式、图题、表格和中英文标题等要求，提交前按 source map O2 核验。
内容层面按以下规则组织：

- 每幅图只回答一个主问题，坐标、单位、图例、样本/参数和不确定性可读。
- 比较图保持尺度和颜色语义一致；不要用双轴制造差异。
- 表格给出定义、单位、样本/实例数和统计/计算口径。
- 主表呈现主张，诊断和扩展表进入附录。
- 图表标题应能独立说明对象、比较和条件；正文解释机制，不复述全部数字。

## 参考文献与作者信息

按官网要求使用顺序编码并核对公开文献、中文文献英文对应、作者、题名、刊名、年份、卷期、页码和
DOI。不要引用无法访问或未公开材料支撑关键事实。基金、作者简介、通讯与单位信息按官网模板准备；
作者顺序和单位应在投稿前确认，避免返修阶段发生受限变更。

## 稿件统稿流程

```text
1. 从官网重新取得模板和排版要求
2. 锁定标题、作者、单位、基金与中英文对应
3. 对齐摘要—研究问题—主结论
4. 运行符号表和公式引用审计
5. 运行图表独立可读性与格式审计
6. 逐条核对参考文献和正文引用
7. 核对附录、证明、算法和正文交叉指针
8. 生成投稿文件并在另一环境检查编译/显示
```

## 微型示例

弱摘要结果句：“仿真结果验证了模型的有效性。”改为：“在所设网络密度与容量范围内，信息延迟
超过阈值后公平约束的边际代价快速上升；滚动策略降低未满足需求，但在低容量情景优势消失。”
后者让读者看到对象、方向、条件和失败边界，且可回查图表。

## 反模式

- 从旧论文复制模板，不核对官网当前下载区。
- 中英文摘要结论、数字或关键词不一致。
- 公式很多但符号未定义、量纲不一致。
- 图表靠正文才能理解，或图题不说明比较条件。
- 参考文献作者/年份/页码由软件自动生成后不校对。
- 把通用写作偏好写成编辑部硬规定。

## 期刊专属拒稿风险

本刊稿件同时可能含模型、证明、算法、仿真和实证，最常见风险是符号、图表与证据边界跨章节失配。
另一个风险是使用过期格式。任何长度、文件、费用、匿名或流程信息都不在本 skill 猜测，应交
`jse-tju-submission` 回查官方来源。
