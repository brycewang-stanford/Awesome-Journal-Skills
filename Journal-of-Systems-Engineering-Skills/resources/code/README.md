# 复现接口（不内置大型代码模板）

本刊近年稿件横跨混合整数优化、博弈解析、复杂网络、仿真、预测、空间计量与 MBSE。
复制某一姊妹包的 Stata 因果推断代码会误导大多数主线，因此本包不提交不可运行的统一模板。

每个项目至少提供以下接口：

```text
project/
├── README.md              # 一条命令复现主结果；软件/求解器版本
├── environment.*          # requirements.txt / environment.yml / Project.toml
├── data/README.md         # 来源、许可、变量、受限数据申请方式
├── src/                   # 模型、算法或估计代码
├── configs/               # 基准参数、情景、随机种子
├── tests/                 # 小实例、守恒/可行性/边界测试
└── outputs/manifest.csv   # 图表编号、生成命令、输入哈希
```

## 各主线的最低测试

- 优化：手工可解小实例、约束可行性、求解器状态、规模梯度。
- 博弈：边界参数、均衡条件、符号结果与数值结果一致性。
- 网络/仿真：固定种子回归测试、多个种子分布、替代拓扑。
- 预测：时间顺序切分、管道防泄漏、naive/经典/强基线。
- 实证：数据构造审计、识别诊断、替代指标/样本/聚类层级。
- MBSE：需求—架构—仿真追溯矩阵与接口一致性。
