## 投稿（修改）指南逐条核实（2022 年 7 月版，官网直读 2026-11-23）

| 事实 | 官方原文要点 |
| --- | --- |
| 审稿制度 | 「本刊实行双向匿名专家审稿制度」 |
| 数据与代码（初审后） | 「初审通过的稿件需要提供文中涉及的原始数据及处理过程，涉及编程的需要提供程序代码，以供审稿使用」 |
| 数据与代码（录用后） | 「收到录用通知的稿件需要提供所用数据、程序及完整结果，可做适当加工，以供学术监督」；作者承诺书第 3 条「同意在官网上公开数据和程序以及附件资料」 |
| 审理期限 / 二次投稿 | 「来稿审理期限一般不少于60个法定工作日」；未通过各审次的稿件「不再接受二次投稿，包括修改稿」 |
| 重复率 | 初审通过稿件经「社科期刊学术不端文献检测系统」检查，「控制在5%以内，包括引用作者自己已发表论文的内容」 |
| 摘要 / 关键词 | [摘要]「字数以450—500字为宜」（附录二：「字数为450—500字」），核心观点与创新占 70% 以上；[关键词]「以3—5个词为宜」 |
| 篇幅 | 「全文以2.5万字左右（不含字符数）为宜。按照每页39行×42字排版，五号宋体，18个页面以上」 |
| 中文摘要构件 | [摘要]、[关键词]、[中图分类号]（只填一个）、[文献标识码]（统一填 A）、[文章编号]（1006-480X（年份）） |
| 英文摘要构件 | Abstract、Key Words、**JEL Classification**；「JEL Classification填写三个，中间用空格隔开，不加标点符号」，示例 `JEL Classification: R12 M58 O18` |
| 基金 / 作者简介 | [基金项目]仅填国家级或省部级，最多填写 3 个；[作者简介]含单位、职称、通讯作者电子邮箱、致谢 |
| 参考文献 | 「实引」制度；文中注「作者（年份）」或「（作者，年份）」；文后注先中文后英文、按字母顺序，按 `作者.题名[J].期刊名,出版年,卷(期):页数.` 等格式著录 |
| 作者承诺书 | 指南附录一，「签字后随同修改论文一同发出」（修改稿阶段随附，非初投必需） |
