# Catalog — every venue in this repository

> Generated by `python3 tools/gen_catalog.py`. Do not edit by hand.

**743 venues** · 289 with a dedicated depth pack · 454 covered as a profile inside a discipline bundle · 556 journals / 187 conferences · 638 international / 105 China.

## How to read this

| Column | Meaning |
|---|---|
| **Coverage** | `depth` — its own pack: a full skill stack across the manuscript lifecycle plus a live-checked `official-source-map.md`. `breadth` — one venue-profile skill (fit, framing, evidence bar, house style, desk-reject triggers) inside a discipline bundle. |
| **Install** | the plugin name for `/plugin install <name>`. Breadth venues share their bundle's plugin. |
| **Lane** | `empirical` / `theory` / `review` / `qualitative` — do not send a qualitative or theory paper to an empirical-only venue. |
| **Tier** | an *indicative bucket*, never a ranking or a bibliometric claim. |

Not sure which venue you want? That is what the matcher is for:

```bash
/plugin install research-toolkit-skills   # then ask rt-journal-match
```

It profiles the paper and shortlists from this same index into reach / match / safe with a resubmission ladder. Its retrieval step is scored in [`shared-resources/journal-selection/eval/`](shared-resources/journal-selection/eval/README.md).
