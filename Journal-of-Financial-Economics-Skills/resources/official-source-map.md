# JFE Official Source Map

Sources used to make this pack specific to the **Journal of Financial Economics (JFE)**, published by Elsevier (North-Holland), ISSN **0304-405X**. All access dates: **2026-05-30** unless a row says otherwise. Submission rules, fees, data/code policy and masthead **re-verified 2026-11-23** against the live jfinec.com pages (submissions, editorial board, data-and-code-sharing policy, additional guidelines), read directly. The Elsevier/ScienceDirect Guide for Authors returned HTTP 403 to automated fetches on 2026-11-23 and was read via search-engine rendering only. Changes found on 2026-11-23: the submissions page now states explicitly that the **manuscript PDF must be anonymous**, that **conflict-of-interest statements for all authors** go in one separate PDF, and that nothing may be uploaded as "Supplementary Material"; the live data-and-code page no longer shows the 1 July 2021 applicability date (see UNVERIFIED).

Where a target fact could not be confirmed from a primary source, the relevant skill marks it **UNVERIFIED** rather than guessing. None of this substitutes for the live submission instructions at submission time — the fee, portal, format rules, editor roster, and data policy all change.

## Editorial-leadership note

- **Editor-in-Chief: Toni M. Whited (University of Michigan), since 2021** (sources 3, 7; re-verified 2026-11-23).
- **Co-Editors: Dimitris Papanikolaou, Philipp Schnabl, Nikolai Roussanov** (source 3; re-verified 2026-11-23 on the live editorial-board page — these three are the Co-Editors listed).
- **Founding Editor: Michael C. Jensen (1974)** (sources 3, 7).
- **G. William "Bill" Schwert** was the long-time **managing editor (1995–2021)** central to JFE's Rochester tradition; he is **not on the current masthead** (sources 3, 7). The pack therefore treats Schwert as historical context, not a current contact.
- Note: **Andrew Karolyi (Cornell)** is associated with the *Review of Financial Studies* (executive editor), **not** JFE's editor-in-chief — do not attribute him to JFE.

## UNVERIFIED items (deliberately not stated as fact in the skills)

- **Acceptance / desk-reject rate.** JFE does not publish a definitive current acceptance rate; the skills call it "very low, typical of top-three finance" and mark the precise figure UNVERIFIED.
- **Registered Reports track.** No JFE Registered Reports / two-stage-review track was found on the official JFE pages at access time; the skills do **not** claim one exists. (The earlier template's speculative "experimented with registered reports" line was removed.)
- **Data/code-policy scope date.** The skills say code + non-proprietary data are mandatory for papers originally submitted on/after **1 July 2021**. On 2026-11-23 the live data-and-code page (source 4) states the requirement for accepted manuscripts but shows no effective date, and the submissions page mentions July 1, 2021 only as the Editorial Manager cut-over for old R&Rs. Kept in the skills; re-confirm before quoting the date.
- **Submission-rights fee reductions.** The submissions page (re-read 2026-11-23) says on-time referees can obtain a code that reduces the fee but gives no amounts; the skills' ~US$567 / US$283 / US$0 schedule is not confirmed on the live page.
- **Generative-AI declaration and 1–7 keywords** come from the Elsevier Guide for Authors (source 6, read via search-engine rendering); whether JFE enforces them at initial submission (jfinec.com is silent) is unconfirmed.
- **Exact current impact factor.** Reported by third parties as roughly high-single to low-double digits; no single official 2024 JCR value confirmed, so the skills do not quote a number.
