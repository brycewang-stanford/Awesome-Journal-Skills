# External Tools - OSDI

Access date: 2026-07-08; links moved to OSDI '27 and re-checked by direct fetch 2026-11-24.

Use these surfaces after reopening the current OSDI cycle pages. OSDI policy is re-set
per edition — two rules changed at OSDI '26 (author response removed, artifact badges
narrowed) and three more at OSDI '27 (separate supplementary files, a senior-reviewer
nomination, a possible early review round) — so never let a cached fact outrank a live
page. Note that `usenix.org` sometimes blocks automated fetches (HTTP 403 in July 2026; it
answered directly on 2026-11-24); if that happens, read
search-engine renderings of the exact URLs and say so in your output.

## Author-side verification passes

Run each pass against the current cycle's pages, not this file:

1. **Calendar pass** — both December deadlines (registration and full paper), their
   exact cutoffs (OSDI '27: 5:59 pm EST = 2:59 pm PST), notification, artifact, and
   final-paper dates; confirm which track (Research vs Operational Systems) the paper is
   registered under, and that Operational titles end with "(Operational Systems)".
2. **Format pass** — page budget for the reviewed body, the reference-page exemption,
   no appendices in the PDF, what goes in the optional separate supplementary files,
   font/text-block specification, and the final-paper budget if accepted.
3. **Anonymity pass** — author and institution anonymization, third-person
   self-citation, and the renamed-system rule: any arXiv/tech-report/talk precursor
   must use a different project name than the submission.
4. **Policy pass** — per-author submission cap, the Volunteer Candidate Senior Reviewer
   (or exemption) on the form, dual-submission rules (NSDI '27 Fall papers are barred
   from OSDI '27), the improvement summary for papers rejected elsewhere, whether an
   author-response phase exists this cycle (none in '26 or '27), the AI rules (no
   wholly/largely AI-written text; disclose coding-agent use in the paper), and the ACM
   Code of Ethics.
5. **Artifact pass** — which badges the current cycle evaluates, the artifact deadline
   relative to notification, and accepted hosting (Zenodo, institutional, third-party
   permanent repositories).

## Do not infer

- Do not project OSDI '26 artifact dates onto OSDI '27; the '27 Call for Artifacts was
  not published on 2026-11-24.
- Do not assume USENIX deadlines are Anywhere-on-Earth; OSDI '27 uses 5:59 pm EST
  (2:59 pm PST).
- Do not assume the badge set or the no-response policy persists — both were changes
  introduced at OSDI '26 and could be reversed.
- Do not carry over "co-located with USENIX ATC" logistics; ATC ended after ATC '25.
- If official pages disagree (HTML CFP vs PDF CFP vs HotCRP), the newest dated revision
  or direct chair communication controls; record the conflict in your output.
