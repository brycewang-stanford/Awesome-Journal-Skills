# OSDI Skills

Twelve agent skills for papers targeting **OSDI — the USENIX Symposium on Operating
Systems Design and Implementation**, the USENIX flagship for operating systems, storage,
distributed systems, cloud infrastructure, and machine-learning systems. The pack covers
the whole arc of an OSDI cycle: deciding whether the contribution is a built-and-measured
system, designing the evaluation, fitting the story into the 12-page reviewed body,
surviving a double-blind review with **no author-response period** (removed at OSDI '26 and
absent from the OSDI '27 CFP), clearing
conditional-accept shepherding, and converting acceptance into an open-access USENIX paper
with a sysartifacts artifact badge.

Official basis **re-verified on 2026-11-24** by direct fetch: the OSDI '27 conference page,
Call for Papers (with its September and October 2026 updates), Requirements for Authors, and
the `osdi27.usenix.hotcrp.com` deadlines page, plus the OSDI '26 conference page and Call for
Artifacts (the latest published artifact call). The original 2026-07-08 pass — OSDI '26 CFP
and author requirements, the USENIX blog posts on OSDI's annual cadence and the retirement of
USENIX ATC — was read through search-engine renderings because `usenix.org` then returned
HTTP 403; the full trail, including everything still marked 待核实, is in
[`resources/official-source-map.md`](resources/official-source-map.md).

## What makes OSDI different from other venues

These mechanics, verified for the OSDI '27 cycle (re-verified 2026-11-24), drive most of the advice in the skills —
and most of the mistakes made by authors arriving from ACM or ML conferences:

- **It is a USENIX venue, not an ACM one.** Proceedings are **open access from the day
  the event begins** — every OSDI paper since the 1990s is a free PDF on `usenix.org`.
  There is no paywall, no ACM DL fee, and no author publication charge.
- **Submission runs on HotCRP**, not OpenReview or CMT, with USENIX's local-time
  convention: OSDI '27 abstracts are due **December 1, 2026** and papers **December 8,
  2026**, both **5:59 pm EST (2:59 pm PST)**, not Anywhere-on-Earth midnight.
- **12 reviewed pages, references free, no appendices in the PDF.** Unlimited reference
  pages, but no appendix material in the submitted PDF; new in '27, **supplementary
  material may be uploaded in separate files** that PC members need not read — so
  everything reviewers weigh must still fit the 12-page body. Accepted papers get 14
  pages plus references.
- **No rebuttal.** OSDI '26 eliminated the author-response period and the '27 CFP
  describes none. The levers sit before submission (clarity — and, if volume requires,
  an **early review round** that reads only the first two pages) and after notification
  (**conditional acceptance with heavyweight shepherding**, no revise-and-resubmit).
- **Every submission brings a reviewer.** New in '27: each paper names a **Volunteer
  Candidate Senior Reviewer** who may be asked to review up to four papers; there is no
  stated target acceptance rate.
- **AI and resubmission rules.** Text wholly or largely generated by AI is fraud;
  coding-agent use in building the system must be disclosed in the paper. Papers rejected
  elsewhere must upload an improvement summary; NSDI '27 Fall submissions are barred.
- **Two reviewing tracks**: the classic Research track and an **Operational Systems
  track** for design-implementation-and-experience papers about deployed systems (titles
  end with "(Operational Systems)").
- **Artifact evaluation via the sysartifacts community**, after conditional acceptance.
  The latest published call (OSDI '26) evaluated only the **Artifacts Available** badge —
  a deliberate narrowing from the earlier Available / Functional / Reproduced triple; the
  OSDI '27 call is not yet published (待核实).
- **Both OS flagships are now annual.** OSDI has run yearly since 2021 and SOSP yearly
  since 2024, so a December OSDI miss retargets within months, not years.
- **Best-paper lineage**: the **Jay Lepreau Best Paper Award**, inaugurated at OSDI '08.

## Installation and use

As a Claude Code plugin (this directory is a self-contained plugin with its own
marketplace manifest):

```bash
# From a clone of the repository
claude plugin marketplace add ./OSDI-Skills
claude plugin install osdi-skills
```

Or use the files directly: each `skills/osdi-*/SKILL.md` is a standalone instruction
file whose frontmatter `description` tells an agent when to trigger it. Typical
invocations:

- "Is this scheduler an OSDI paper or an NSDI paper?" → `osdi-topic-selection`
- "Audit my draft against the OSDI submission rules" → `osdi-submission`
- "We got a conditional accept — what now?" → `osdi-author-response`, `osdi-camera-ready`
- "Prepare the artifact for the badge" → `osdi-artifact-evaluation`

## Suggested use

1. **Months before the deadline** — run `osdi-topic-selection`; if nothing is built and
   measured, the fit test just saved you a cycle. Study the exemplars library to see how
   accepted OSDI papers put a working system at the center.
2. **While building** — keep `osdi-experiments` and `osdi-reproducibility` beside the
   test cluster; workload realism and measurement provenance cannot be retrofitted in
   deadline week.
3. **While writing** — `osdi-writing-style` for the 12-page narrative,
   `osdi-supplementary` for the body/supplement triage, `osdi-related-work` for positioning
   against the freely downloadable OSDI/SOSP/NSDI record.
4. **December** — `osdi-submission` end to end: title registration a week before the
   paper, 5:59 pm EST cutoffs, anonymization down to the institution and system name.
5. **After notification** — `osdi-review-process` to read the decision,
   `osdi-author-response` for the shepherding exchange, `osdi-artifact-evaluation` and
   `osdi-camera-ready` for the May–June deliverables.

## OSDI '27 anchor facts (dated snapshot, not permanent rules)

- OSDI '27 is the **21st** edition: Hyatt Regency Baltimore Inner Harbor, Baltimore, MD,
  USA, **July 7–9, 2027**. Program Co-Chairs: Philip Levis (Stanford University and Google)
  and Junfeng Yang (Columbia University).
- 2027 pipeline: abstract registration **December 1, 2026** · complete papers
  **December 8, 2026** (both 5:59 pm EST / 10:59 pm UTC, on HotCRP) · notification
  **March 16, 2027** · final papers **June 3, 2027**. Artifact dates 待核实 (call not yet out).
- Format: **12 pages** including figures and tables plus unlimited references at
  submission; **no appendices** in the submitted PDF; optional **supplementary files**;
  **14 pages** plus references for accepted papers.
- Policy: double-blind, institutions anonymized (Research track), arXiv posting allowed
  only under a different system name, at most **eight submissions per author**, a
  Volunteer Candidate Senior Reviewer per paper, possible early review round, no
  author-response period, conditional acceptance with shepherding, no revise-and-resubmit,
  ACM Code of Ethics.
- Publication: USENIX **open-access** proceedings, free to all once the event begins;
  no author fee; at least one full-price registration per accepted paper.
- History: OSDI '26 (20th) met in Seattle, July 13–15, 2026 (co-chairs Eddie Kohler and
  Amar Phanishayee; papers due December 11, 2025; only the Artifacts Available badge).

## Fact discipline

This pack separates three classes of statement, and the skills are written to keep them
distinguishable:

1. **Verified OSDI '27 facts** — carry dates/caps and trace to a numbered source in
   the source map (e.g., the 12-page body, the December 8, 2026 deadline, the senior
   reviewer nomination).
2. **Reported facts** — found only in secondary renderings and labeled as such.
3. **Unverifiable-at-check-time items** — explicitly marked 待核实 and phrased as
   questions to resolve, never as facts (e.g., the OSDI '27 artifact badges, whether the
   early review round runs, registration rates).

If any statement in the skills presents class 2 or 3 material as class 1, treat it as a
bug and fix it against the live official pages.

## Maintenance notes

- Every date and cap above is an **OSDI '27 snapshot** (re-verified 2026-11-24); reopen the current
  `usenix.org/conference/osdi<yy>` pages before giving deadline-sensitive advice.
- The author-response and artifact-badge policies **changed at OSDI '26** (response
  removed; badges narrowed to Available-only), and the supplementary-file, senior-reviewer
  and early-review rules **changed at OSDI '27**. They may change again — check the
  current CFP and Call for Artifacts rather than assuming either direction.
- USENIX ATC ended after ATC '25 and its successor is run by ACM SIGOPS; do not cite
  "co-located ATC" logistics from pre-2026 OSDI pages.
- OSDI chairs rotate per edition; there is no standing editor. Re-check the current
  organizers page before naming anyone.
- When adding exemplar papers, follow the verification recipe at the end of
  [`resources/exemplars/library.md`](resources/exemplars/library.md) — famous systems
  papers scatter across OSDI, SOSP, NSDI, and ATC, and the venue must be proven, not
  remembered.
